# AI 可视冲牙器系统

本目录用于规划“带摄像头的冲牙器硬件＋配套软件”系统。

当前状态：**阶段 0 已确认｜黑客松 HTML 演示修订中**

阶段 0 已完成系统、数据、体验、安全与验收规划；当前另有一个离线 HTML 演示，用于展示核心产品闭环。

项目约束：**本项目不使用 Git**，不初始化仓库、不暂存、不提交。

## 已确认的产品方向

- 首个平台：iOS。
- 系统保留 Wi‑Fi 样机接入，并新增 USB 摄像头直连模式；当前黑客松现场优先使用 USB 样机演示真实画面。
- 用户可以实时观察、拍照、建立个人牙齿画像并回顾多年历史。
- 系统以“用户—牙齿—区域—事件”为长期记录主线。
- 记录分为用户记录、设备记录、AI 辅助记录和医院确认记录。
- AI 可针对蛀牙、牙龈发炎、肿胀、牙结石等明显可见特征给出清楚的基础初筛判断、图片对比和建议；最终确诊由医师完成。
- 用户可从照片或历史事件发起 AI 查看或医生咨询。
- 所有照片、报告、对话、补拍与复查归属于同一个“牙齿问题事件”。
- 用户可开启“距离上次清洁多久”的习惯提醒，提醒不评价清洁结果。
- 长期支持个人端与医院端双域隔离、授权交换和医院协作。
